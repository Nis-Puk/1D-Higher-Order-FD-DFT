This is the python project was coded as part of the poster presentation in NE451 at University of Waterloo in the Fall term 2026. All rights are preserved.

Within our project "Investigating the Impact of Higher-Order Finite-Difference Discretization in One-Dimensional DFT" we were particular intested in the influence of 2nd, 4th and 8th order finite difference approximations in 1D Kohn Sham DFT. Within the 3 test cases we intestigate different potentials resulting in a full SCF test.

The implementation of the 1D DFT code was validated with the pyscf package within the pyscf_benchmark.py file.

If you want to run the code yourself, please also download the figures folder since the 1D Higher-Order FD DFT code need the figures folder in the programm folder.
